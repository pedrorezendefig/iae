# IAE: mapa do repositório

Este é o repositório dos sócios Pedro, Rib e Lucas para o projeto do IAE, a escola de prática jurídica para advogados in-house. O projeto está parado desde 13/11/2026 e pode voltar em março de 2027. Enquanto isso, o repositório guarda o glossário, as decisões da Plataforma de cursos e a marca do Cliente.

| Pasta ou arquivo | O que tem |
|---|---|
| `README.md` | Este mapa |
| `CLAUDE.md` | As regras do repositório para o agente: situação do projeto, idioma, tipografia e trabalho por PR |
| `CONTEXT.md` | O glossário do projeto (Sócio, Cliente, Aluno, Curso, Vídeo, Operador e os outros termos) |
| `docs/adr/` | As decisões da Plataforma de cursos, com o índice em `docs/adr/README.md` |
| `docs/marca/` | O manual de identidade visual do IAE e uma referência de interface em imagem |
| `docs/comercial/` | Fora do git, só na máquina do Pedro: a proposta ao IAE, os protótipos e a cópia das issues apagadas |
